# Fase 2 - Perfil e Carreira

Esta fase cria a base de identidade do jogador: nome artístico, país, cidade, avatar provisório, traços e progressão inicial.

## Regras mantidas
- Fullscreen landscape mobile.
- Aviso obrigatório para virar o celular.
- Build version visível no app.
- Anti-break ativo.
- Assets organizados para troca futura sem quebrar caminhos.
