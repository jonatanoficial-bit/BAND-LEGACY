# Band Legacy - Phase 7 Release System

Versao: v0.7.0_20260519_2136

## Objetivo
Adicionar o sistema comercial de lancamento musical: singles, EPs, albuns, plataformas, campanhas, charts, reviews, streams, hype, receita e impacto na reputacao.

## Sistemas entregues
- Tela Lançamento Musical
- Selecao de master finalizada
- Formato de lancamento: Single, EP, Album, Live Session
- Plataformas foco: Global Stream, RockWave, ClipTube, Indie Radar, Radio Network
- Sliders de marketing, clipe/conteudo visual e PR/imprensa
- Previsao de hype, streams, critica e chart
- Publicacao com custo, receita, fans, XP e reputacao
- Catalogo publico dos lancamentos
- Feeds de reviews e social buzz
- Background provisorio em assets/backgrounds/release/

## Anti-quebra
- Se nao houver master finalizada, o sistema cria candidato provisorio a partir das composicoes/demos.
- Se caixa for insuficiente, o lancamento nao quebra o save e exibe mensagem segura.
- Save local migra automaticamente de versoes anteriores.
- Todos os assets seguem paths fixos para substituicao futura.
