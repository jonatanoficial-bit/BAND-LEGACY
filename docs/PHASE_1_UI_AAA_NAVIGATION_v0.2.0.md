# Fase 1 — UI AAA + Navegação

Versão: `v0.2.0_20260522_1501`

## Objetivo

Aproximar o protótipo de Band Legacy das imagens de referência: estética rock/metal cinematográfica, paleta preta/dourada, painéis premium, botões com brilho, fundos por tela, navegação funcional e leitura melhor em PC e mobile horizontal.

## Entregue nesta fase

- Versão visível no jogo.
- Título da build atualizado.
- CSS de reconstrução visual AAA aplicado sobre a base existente.
- Telas principais com fundos cinematográficos por contexto.
- Botões com hover, foco, brilho, seleção e microinteração.
- Melhoria do aviso de rotação mobile.
- Tentativa de fullscreen + orientação horizontal após toque do jogador.
- Navegação preservada entre menu, criação, lobby, estúdio, show, staff e sistemas já existentes.
- `VERSION.txt`.
- `BUILD_INFO.json`.
- `ASSET_PATHS_REQUIRED.md`.

## Limites desta fase

- Os assets ainda são provisórios.
- A jogabilidade profunda continua para fases posteriores.
- Navegadores mobile não permitem fullscreen/orientation lock automático sem toque do usuário; por isso o jogo avisa e solicita interação.

Fase 2 — Mobile horizontal/fullscreen hardening + ajustes específicos de HUD em celulares e tablets.
