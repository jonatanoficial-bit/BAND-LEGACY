# Band Legacy - Phase 12 Dynamic Events

Adds dynamic narrative systems for conflicts, interviews, fan campaigns, sponsor pressure, backstage problems, awards, crisis control and career consequences.

## Included
- New Eventos Dinâmicos screen
- Event generation and resolution
- Choice system with risk/reward
- Tone selector
- Morale, ego and crisis-control metrics
- Cash, fans and XP consequences
- Persistent event history in localStorage
- Placeholder event background in official asset folder

## Anti-break
The system uses fallback state creation, safe screen routing, localStorage recovery and modular placeholder assets.
