# Band Legacy - Phase 3 Band System

Implementado nesta build:
- Tela de Banda jogável.
- Edição de nome da banda, formação e gênero principal.
- Integrantes com função, atributos, moral, ego e lealdade.
- Cálculo de overall, sinergia, moral, energia, criatividade e risco de conflito.
- Salvamento local seguro com migração automática de saves antigos.
- Slots de assets preparados para avatares, logos e UI definitiva.
- Anti-quebra mantido: fallback de tela, logs, recuperação de save, assets obrigatórios e proteção de ações.

A próxima fase recomendada é Fase 4 - Sistema de Staff.
