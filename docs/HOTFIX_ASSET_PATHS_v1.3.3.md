# HOTFIX ASSET PATHS v1.3.3

Build criada para preservar a estrutura completa do projeto original e alterar apenas os caminhos necessários para reconhecer os assets renomeados.

## Como instalar os assets

1. Extraia esta build.
2. Extraia `VALE_GAMES_ASSETS_ORGANIZADOS.zip`.
3. Copie a pasta `assets/` do pacote de assets para dentro de `BAND-LEGACY-main/`.
4. A estrutura final deve ficar:

```text
BAND-LEGACY-main/
  index.html
  script.js
  style.css
  assets/
    backgrounds/
    characters/
    logos/
```

## Observação

Este ZIP não inclui imagens. Ele inclui apenas os arquivos do jogo e os caminhos de referência.
