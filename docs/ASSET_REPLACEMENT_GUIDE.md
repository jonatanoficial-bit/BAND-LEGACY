# ASSET REPLACEMENT GUIDE — Band Legacy

## Regra principal

Substitua artes provisórias por artes oficiais mantendo o caminho atual sempre que possível. Se o nome final for alterado, atualize também:

1. `ASSET_PATHS_REQUIRED.md`
2. `data/assets/asset_manifest.json`
3. mapa de backgrounds em `script.js`
4. qualquer referência direta em `style.css`

## Prioridade P0 antes da venda

- Menu principal
- Lobby
- Estúdio
- Show ao vivo
- Botões principais
- Avatar inicial
- Painel principal

## Exportação

Dentro do jogo, abra **Assets** e clique em **Exportar manifesto** para gerar o JSON que pode ser enviado para outra IA/artista.
