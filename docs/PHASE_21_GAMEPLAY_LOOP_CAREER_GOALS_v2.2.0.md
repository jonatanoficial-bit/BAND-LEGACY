# Fase 21 — Refino de Gameplay, Metas e Loop Divertido

Build: `v2.2.0_gameplay_loop_career_goals_20260618_1815`

## Objetivo
Deixar o jogo mais claro e divertido no curto prazo, com metas visíveis, recompensas e um loop semanal que orienta o jogador sem travar a liberdade.

## Implementado
- Nova tela `Metas de Carreira`.
- Sistema persistente de metas com progresso automático.
- Recompensas resgatáveis em caixa, XP e fãs.
- Momentum de carreira.
- Próximo passo recomendado.
- Loop semanal com atalhos para:
  - composição;
  - estúdio;
  - lançamento;
  - show;
  - narrativa.
- Histórico de recompensas.
- Botão para resgatar todas as metas concluídas.
- Migração anti-quebra para saves antigos.
