# HOTFIX — Scroll PC e Mobile v1.3.1

Versão: `v1.3.1_20260522_1948`

Correção aplicada para permitir rolagem vertical fácil em todas as telas longas do jogo.

## Corrigido

- PC: rolagem com mouse wheel e trackpad dentro da tela ativa.
- Mobile: rolagem com dedo em tela horizontal.
- Telas longas deixam de depender de TAB para alcançar botões abaixo da dobra.
- Preservado fullscreen horizontal e aviso de rotação.
- Adicionado reset de scroll ao trocar de tela para começar sempre no topo.

## Observação

O navegador continua exigindo toque do usuário para liberar fullscreen/orientation lock em celulares, por segurança do próprio browser.
