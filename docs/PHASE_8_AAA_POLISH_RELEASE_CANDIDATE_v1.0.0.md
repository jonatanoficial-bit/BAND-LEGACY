# BAND LEGACY — FASE 8
## Polimento AAA e Release Candidate

**Versão:** v1.0.0_20260522_1829  
**Build:** Band Legacy Release Candidate - AAA Polish

## Objetivo
Transformar a base jogável criada nas fases anteriores em uma Release Candidate preparada para testes comerciais, mantendo o padrão visual dark cinematic rock/metal, versão visível no jogo, mobile horizontal e estrutura internacional.

## Implementado

- Tela de loading cinematográfica.
- Tutorial inicial de primeiros passos.
- Botão para reabrir tutorial em Settings e na tela Release Candidate.
- Áudio de interface com desbloqueio seguro após toque do usuário.
- Toggle de áudio em Settings.
- Tela Release Candidate com checklist de build.
- Exportação de backup do save em JSON.
- Ajuste de balanceamento semanal: crescimento de fãs, caixa mínimo e XP semanal.
- Integração do polimento com o fluxo já existente: main menu, lobby, save system, composição, estúdio, lançamento, show, turnês, economia, eventos e mercado.
- Versão visível atualizada para `v1.0.0_20260522_1829`.

## Itens ainda necessários antes de venda internacional definitiva

1. Substituir todos os assets provisórios por artes oficiais finais.
2. Testar em aparelhos reais Android e iOS.
3. Revisar 100% dos textos dinâmicos em português, inglês e espanhol.
4. Criar sons oficiais de UI e SFX de palco.
5. Fazer balanceamento econômico longo, com campanhas de 20 a 100 semanas.
6. Revisar acessibilidade, contraste e tamanho de toque em aparelhos pequenos.
7. Preparar página de venda, trailer e screenshots oficiais.

## Política de assets
Esta build mantém os caminhos oficiais. Caso assets pesados sejam removidos em um pacote futuro, o arquivo `ASSET_PATHS_REQUIRED.md` deve continuar indicando exatamente onde cada imagem oficial precisa ser colocada.
