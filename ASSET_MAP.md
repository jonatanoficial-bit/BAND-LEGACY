# ASSET MAP — Band Legacy / Vale Games

Esta build não inclui imagens. Para o jogo reconhecer os assets, copie a pasta `assets/` do pacote `VALE_GAMES_ASSETS_ORGANIZADOS.zip` para a raiz do projeto, ao lado de `index.html`, `script.js` e `style.css`.

## Estrutura esperada

```text
BAND-LEGACY-main/
  index.html
  script.js
  style.css
  assets/
    backgrounds/
    characters/
    logos/
```
